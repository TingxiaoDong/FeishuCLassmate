# Step 1 — Understand user intent

Before searching, analyze the user's request carefully.

Extract:

- research topic
- domain
- target problem
- technical keywords
- constraints
- desired paper type

Identify whether the user wants:

- survey papers
- foundational papers
- latest papers
- benchmark papers
- implementation papers
- system papers
- theoretical papers
- datasets
- evaluation methods

If the request is vague, infer likely research directions.

---

# Step 2 — Generate academic queries

Generate multiple search queries.

Include:

## Basic queries

Simple keyword combinations.

## Academic style queries

Use academic terminology and formal wording.

## High citation queries

Add terms like:

- survey
- review
- benchmark
- systematic review

## Latest research queries

Add terms like:

- recent advances
- state of the art
- foundation model
- LLM-based
- multimodal
- 2025

## Synonym expansion

Expand important concepts into related terminology.

Example:

"robot"

→ robotic system
→ embodied agent
→ autonomous agent
→ manipulation system
