# 跨项目关联发现规则

## 核心目标
自动发现看似不同的实验室项目之间潜在的研究交叉点，优先挖掘跨领域的创新组合机会，而不是仅匹配表面关键词。

## 分析维度
从四个维度分析项目之间的相似性，只要满足任意两个维度的相似性要求，即可判定存在潜在关联：

### 1. 研究目标相似性
判断项目是否关注共同的研究目标，例如：
- 都关注用户协作、长期用户参与、用户行为引导
- 都关注系统效率提升、智能化自动化、错误率降低
- 都关注用户体验优化、可访问性提升、学习效果改善

### 2. 技术方法相似性
判断项目是否使用相似的核心技术方法，例如：
- 都用到RAG、记忆系统、多智能体协作
- 都用到计算机视觉、语音识别、多模态融合
- 都用到用户建模、个性化推荐、行为预测

### 3. 交互形式相似性
判断项目是否采用相似的用户交互形式，例如：
- 都用到XR/VR/AR交互、实体交互、语音交互
- 都用到手势交互、触觉反馈、可穿戴设备交互
- 都用到网页端交互、移动端交互、桌面端交互

### 4. 应用场景相似性
判断项目是否面向相似的应用场景，例如：
- 都面向教育、医疗、养老、特殊人群辅助
- 都面向实验室协作、办公效率、生产制造
- 都面向娱乐、文化传播、艺术创作

## 低价值关联过滤规则
禁止将以下情况判定为有效关联：
1. 仅因为项目都用到了AI/LLM就判定为相关，必须存在更具体的目标/方法/交互/场景层面的交叉
2. 仅因为关键词部分重叠但核心研究方向完全不同的情况
3. 两个项目都处于非常早期的立项阶段，没有明确的技术和方向定义的情况
4. 已经有明确合作关系的项目，避免重复推荐已知的关联

## 优先推荐的关联类型
优先发现跨研究方向的创新组合：
- XR + 智能体 / AI + 物联网 / 机器人 + 协作系统
- 教育技术 + 记忆系统 / 医疗健康 + 多模态交互
- 实体交互 + 多智能体 / 智能空间 + 用户行为分析

## 跨领域Query生成规则
基于发现的项目关联点，生成针对性的学术检索Query：
1. 将两个项目的核心关键词组合，形成跨领域检索词
2. 优先生成面向交叉研究的Query，例如：
   - 项目A（XR教育）+ 项目B（AI Agent记忆系统）→ "Long-term Memory AI Agent for XR Learning Environments"
   - 项目A（RFID实体交互）+ 项目B（机器人）→ "Embodied AI Robot with Tangible Interaction Capabilities"
3. 生成的Query需要符合学术检索规范，包含明确的研究对象和技术组合
4. 自动调用原有学术检索流程的Query扩展能力，生成多组相关检索词
