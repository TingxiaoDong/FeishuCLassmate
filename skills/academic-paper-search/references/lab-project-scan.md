# Lab项目扫描规则与语义快照格式

## 扫描范围
优先扫描飞书知识库中标记为「项目」的文档，包括：
- 项目立项文档
- 项目进展周报/月报
- 项目结题报告
- 项目技术方案文档
- 学生开题/毕设文档

## 提取字段
从项目文档中自动提取以下信息，生成项目语义快照：
| 字段名 | 说明 |
|--------|------|
| 项目名称 | 项目的正式名称 |
| 负责人 | 项目的主要负责人/学生姓名 |
| 项目主题 | 项目核心研究方向的一句话总结 |
| 技术关键词 | 项目使用的核心技术栈关键词（如RAG、多智能体、计算机视觉等） |
| 研究方法 | 项目采用的核心研究方法（如用户研究、对比实验、系统构建等） |
| 数据集 | 项目使用的公开/私有数据集名称 |
| 研究对象 | 项目的核心研究对象（如学生、老人、机器人、XR环境等） |
| 应用场景 | 项目的落地应用场景（如教育、医疗、智能办公、实验室协作等） |
| 交互形式 | 项目涉及的用户交互形式（如XR交互、语音交互、实体交互、网页交互等） |
| AI能力 | 项目用到的AI核心能力（如大语言模型、语音识别、动作捕捉、推荐算法等） |
| 当前阶段 | 项目当前所处阶段（如立项、进行中、待结题、已结题） |
| 最近更新时间 | 项目文档的最后修改时间 |

## 语义快照示例
```yaml
项目名称: XR沉浸式教育系统
负责人: 张三
项目主题: 基于XR技术的AI辅助教学系统研发
技术关键词: XR, AI Tutor, 多模态交互, 知识图谱
研究方法: 对照实验, 用户体验评估, 系统开发
数据集: 中小学数学题库, 用户行为日志数据集
研究对象: 初中学生, 授课教师
应用场景: 中小学教育, 课后辅导
交互形式: VR头显交互, 语音交互, 手势交互
AI能力: 大语言模型, 语音识别, 个性化推荐
当前阶段: 进行中
最近更新时间: 2026-05-10
```

## 扫描规则
1. 每日凌晨扫描所有在24小时内更新的项目文档，增量更新语义快照
2. 每周一全量扫描所有项目文档，更新所有语义快照
3. 提取内容优先从文档的摘要、关键词、核心章节获取，避免提取无关的会议记录、后勤信息
4. 语义快照存储在飞书多维表格中，供跨项目关联分析模块调用
