# Step 3 — Search strategically

Search broadly first.

Then narrow down based on:

- highly relevant papers
- repeated keywords
- influential authors
- citation relationships
- common methodologies

Use iterative refinement.

---

# Step 8 — Iterative improvement

If results are weak:

- reformulate queries
- broaden terminology
- narrow scope
- switch academic sources
- expand synonyms
- pivot toward neighboring domains

Continue refining until relevance improves.
