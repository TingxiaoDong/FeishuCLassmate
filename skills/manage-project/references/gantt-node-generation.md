# 甘特图节点生成指南

## 前置准备
调用 `feishu_classmate_data_layout()` 获取配置：
- 所有项目资源默认写入飞书【Lab知识库】公共协作区
- 项目列表统一维护在【公开项目】文档

## 生成甘特图节点（从文档创建和自然语言创建通用）
用户确认项目文档内容无误后：
1. 将项目文档正式写入【Lab知识库】公共协作区
2. 新增项目到【公开项目】文档索引
3. 根据文档中的任务节点信息，生成甘特图初始节点写入`gantt`多维表格
4. 计算任务密度和时间紧急度，判断是否为高优先级项目
5. 高优先级项目自动创建专项跟踪表并通知相关人员

## 高优先级项目判断规则
- 任务密度 = 总任务数 / 总天数
- 同时满足：任务密度 > 0.5 且 剩余天数 < 7天 → 标记为「高优先级（任务重时间紧）」
- 高优先级项目自动执行：
  1. 更新项目优先级字段
  2. 在`high_priority_projects`多维表新增跟踪记录
  3. 发送通知给项目负责人和导师
