# 准备期 · 详细步骤

## 输入收集

从用户消息中提取:

- 访客单位/称谓(必填语义)
- 来访日期(默认今天)
- 是否强调某些展区或忌口话题

## 读母版

- `plugin_docs.tourTemplate` 可为 Doc token、文档 URL 或由 wiki 搜索得到的定位符。
- 母版中建议使用占位符:`{{访客单位}}`、`{{日期}}`、`{{实验室名称}}`,便于替换。

## 生成正文约束

- **保密**:不得写入保密项目;公开内容仅来自母版、`plugin_docs.publicProjects` 对应 Doc、以及 `labInfo`(配置)。
- **章节**:必须包含 [doc-format.md](./doc-format.md) 所列二级标题,便于 `lab-tour-run` 分段播报。
- **唤醒句**:在文档末尾固定一节「唤醒」,写一句口语化口令,例如:「飞书同学,XX 单位的老师到了。」供 Temi / 飞书触发执行期 skill。

## 交付物

- 新建 Doc 的 **document_id** 与 **URL**(发给教师归档)。
- 可选:在同一机器人会话置顶摘要「访客 + doc 链接」,便于现场人手忙脚乱时复制。
