# 当次导览 Doc · 推荐 Markdown 结构

执行期 skill 按 **二级标题 `##`** 切分段播报。请生成稿至少包含以下章节(标题字面保持一致以便检索):

```markdown
## 开场
## 实验室概况
## 特色实验区
## 工位区
## 人形机器人展区
## 仿真与生活模拟区
## 收尾与问答
## 唤醒
```

说明:

- **特色实验区**:可与 `labInfo.specialAreas` 点位对齐;若稿内写了 Temi 导航点名,须与机器人地图保存的名称一致(如 `入口`、`工位区`)。
- **工位区**:可简述要点;执行期会再拉取 Public Projects 补充。
- **唤醒**:一句固定口令,供口头触发。

若某展区暂无内容,写一行「本节跳过」即可,执行期仍会尝试导航若配置了 `specialAreas`。
