# 当次导览 Doc · 推荐 Markdown 结构

执行期 skill 按 **二级标题 `##`** 切分步骤执行，每步骤支持「动作指令 + 讲解内容」的精确控制格式。

## 格式规范
每个章节由 **动作指令块** 和 **讲解内容** 两部分组成：
1. 动作指令块：以 `【动作：XXX】` 开头，支持的动作类型：
   - `【动作：导航到 XXX】` - 控制Temi导航到指定点位（点位名称必须与机器人地图保存的名称一致：入口、充电桩、工位区、会议室、实验室、生活仿真区、硬件台）
   - `【动作：抬头 XX 度】` - 控制Temi抬头指定角度
   - `【动作：转向 XXX】` - 控制Temi旋转方向
   - `【动作：等待】` - 暂停等待用户互动
   - 无动作指令：直接播放讲解内容
   
2. 讲解内容：动作执行完成后Temi会朗读的内容

## 双语导览规则（外国来宾必用）
- 若来宾为外国人，每个章节正文必须按以下顺序组织：
  1) 中文讲解
  2) 来宾国家语言讲解
- 推荐标记格式：
  - `中文：...`
  - `访客语（<语言名>）：...`
- 保持两种语言语义等价，避免一长一短导致信息缺失。

## 基础章节模板（可根据访客兴趣动态调整顺序）
```markdown
## 开场
【动作：导航到 入口】【动作：抬头 15度】
嗨，欢迎来到我们实验室～我是飞书同学，平时也在这里“上班”，大家有什么找不到的资料、卡住的问题，也会来问我。今天就由我带大家逛一圈，如果中途有好奇的地方，随时打断我就好，我很喜欢被问问题。

## 实验室概况
先简单跟大家说一下我们在做什么。这个实验室主要是在研究“让最前沿的机器人技术走进人的日常”。方向比较交叉一点，比如人机交互、服务设计、XR体验，还有人和AI怎么一起工作这些。

## 特色实验区
【动作：导航到 特色实验区】
这里是我们的特色实验区，主要进行XX方向的研究...

## 工位区
【动作：导航到 工位区】
这边就是大家平时待得最多的地方。可以看到每个人桌上都不太一样，有的在做交互原型，有的在接传感器，还有的可能在调一些奇奇怪怪的设备。

## 人形机器人展区
【动作：导航到 人形机器人展区】
这边可以算是我的“同类”区域了。这些是实验室在做的一些实体机器人相关探索...

## 仿真与生活模拟区
【动作：导航到 生活仿真区】
然后这里是生活仿真区。你可以把它理解成一个“稍微被设计过的日常环境”...

## 收尾与问答
【动作：导航到 入口】
差不多就是这样啦～接下来就交给大家了。如果你们想更深入了解某个项目，或者好奇我是怎么工作的，也可以直接问我。

## 唤醒
飞书同学，开始导览
```

说明:
- **章节顺序可灵活调整**：根据访客兴趣匹配度动态排序，高匹配度区域优先展示
- **点位名称必须严格匹配**：导航指令中的点位名称必须与机器人地图中保存的名称完全一致
- **工位区**：可简述要点；执行期会再拉取 Public Projects 补充
- **唤醒**：一句固定口令，供口头触发
- **跳过章节**：若某展区暂无内容，写一行「本节跳过」即可，执行期会自动跳过该章节
- **外国来宾双语**：章节正文采用“中文 + 访客国家语言”双语结构
